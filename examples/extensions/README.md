# Example extensions

These are not auto-loaded.

Current examples:

- `capability-lab` — exercises invalidation, focus, tool snapshots, decorations, roles, and diagnostics
- `doom-lab` — mounts Doom in a workbench tool

If you want to try one, copy its folder into:

- `.the-editor/extensions/` for the current project
- `~/.the-editor/extensions/` for a global install

Then restart the Electron app or run `:reload`.
